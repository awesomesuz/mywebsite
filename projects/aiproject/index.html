AI Project

Sentiment Classifier with NLP

Understand emotions in text. Train the AI with your feedback.

  • ✅ What we built so far
    A training interface where you label real comments as positive, negative, or neutral. Every label is stored in a D1 database via Cloudflare Workers — ready to become training data.
  • 🔄 How you help
    Your annotations will be used to train a sentiment classifier using NLP techniques (TF‑IDF + a lightweight model). No AI magic yet — your input makes it possible.
  • 🚀 What’s next
    After collecting enough labeled data, we’ll train a production model and deploy a live API for real‑time sentiment prediction — all powered by your contributions.
